───────────────────────────────────────────────────────────────────────────────
 COMUNICAÇÃO FRONTEND → BACKEND
───────────────────────────────────────────────────────────────────────────────

O frontend Next.js deve consumir apenas endpoints públicos/controlados do backend.

Exemplos:

GET    {NEXT_PUBLIC_API_URL}/api/grupos-gerenciador?limit=50
GET    {NEXT_PUBLIC_API_URL}/api/grupos/{grupo_id}
PUT    {NEXT_PUBLIC_API_URL}/api/grupos/{grupo_id}
GET    {NEXT_PUBLIC_API_URL}/api/stats
POST   {NEXT_PUBLIC_API_URL}/api/reload-sheets
GET    {NEXT_PUBLIC_API_URL}/api/refresh

O frontend NÃO deve chamar diretamente:

- API da PipeRun
- Google Sheets API
- Service Account Google
- Qualquer endpoint que exija token privado

Essas chamadas devem continuar sendo feitas pelo FastAPI no Render.

───────────────────────────────────────────────────────────────────────────────
 CORS NO BACKEND
───────────────────────────────────────────────────────────────────────────────

Como o frontend ficará na Vercel e o backend no Render, o FastAPI precisa liberar
CORS para os domínios corretos.

Exemplo recomendado em backend/main.py:

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=[
        "https://crediclass.csrtecnologia.com.br",
        "https://crediclass-dashboard.vercel.app",
        "https://*.vercel.app"
    ],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

Em produção, depois que o domínio final da Vercel estiver definido, remover
origens genéricas e manter apenas os domínios oficiais.

───────────────────────────────────────────────────────────────────────────────
 FIX CRÍTICO: CACHE EM MEMÓRIA (Descoberto 2026-05-27)
───────────────────────────────────────────────────────────────────────────────

### PROBLEMA ENCONTRADO
Render usa cache em memória que NÃO era atualizado quando o arquivo JSON era
modificado via PUT. Resultado:
  - Arquivo JSON atualizado: valor = 88.88 ✓
  - API retorna em memória: valor = 58.75 ✗

Fluxo que FALHAVA:
  1. Frontend envia PUT com novo valor
  2. Backend salva no arquivo JSON (✓)
  3. Mas API continua retornando valor antigo (cache em memória) (✗)
  4. Frontend mostra valor novo temporariamente mas próxima leitura mostra valor antigo

### SOLUÇÃO IMPLEMENTADA
Adicionar `force_refresh=True` ao chamar `fetch_grupos()` no endpoint PUT:

ANTES:
    grupos = fetch_grupos()

DEPOIS:
    # CRÍTICO: Forçar refresh do cache para evitar dados desatualizados
    grupos = fetch_grupos(force_refresh=True)

Isso força releitura do arquivo JSON ao atualizar, garantindo sempre dados
atualizados.
